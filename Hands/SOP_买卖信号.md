# SOP 买卖信号

> 分析买卖时机 + 止损位设定
> 触发暗号：`规划买卖点 [ticker]`

---

## 一、流程概述

| Step | 动作 | 输入 | 输出 |
|:---|:---|:---|:---|
| 1 | 读取上下文 | 个股基础知识库 + 当前偏好 | 了解个股基本面和用户风格 |
| 2 | 估值分析 | P18/P19 估值面部分 | 估值评级 |
| 3 | 技术分析 | P18/P19 技术面部分 | 技术评分 |
| 4 | 资金分析 | P18/P19 资金面部分 | 资金评级 |
| 5 | 综合判断 | 三维度结果 | 买入/卖出/持有建议 |
| 6 | 仓位规划 | P20 仓位纪律 | 具体执行计划 |

---

## 二、前置条件

执行前必须：
1. 已读取 `持仓与关注/当前关注方向与投资偏好.md`
2. 已读取目标股票的 `个股基础知识库.md`（如有）
3. 已获取目标股票当前价格和近期走势数据

---

## 三、详细流程

### Step 1：读取上下文

```
读取文件：
  → 持仓与关注/当前关注方向与投资偏好.md（用户风格）
  → 持仓与关注/持仓/[股票]/个股基础知识库.md（个股基本面）
  → 持仓与关注/持仓/[股票]/买入卖出备忘录.md（如有）

确认：
  → 用户投资周期：短线几天
  → 用户技术偏好：3 日金叉 11 日均线 + 放量确认 + 红量为主
  → 用户禁忌：不追涨停板、不碰 ST
```

### Step 2：估值分析

调用 P18/P19 估值面部分：

```
估值面分析：
  1. 查 PE 历史百分位
     → 短线买入区间：< 40%
     → 短线卖出区间：> 60%

  2. 查 PB 历史百分位
     → 买入区间：< 30%
     → 卖出区间：> 70%

  3. 计算 PEG（如有数据）
     → 买点：< 0.8
     → 卖点：> 1.5

输出：
  → 估值评级：低估/合理/偏高/高估
  → 是否满足买入条件
  → 是否触发卖出警示
```

### Step 3：技术分析

调用 P18/P19 技术面部分：

```
技术面分析（短线标准）：

买入信号检查：
  ☐ 均线突破：股价站上 20 日均线且站上 3 天不跌破
  ☐ 均线金叉：3 日均线金叉 11 日均线（用户偏好）
  ☐ 成交量放大：> 5 日均量 × 1.5 倍
  ☐ MACD 金叉：零轴下方金叉或红柱放大
  ☐ 纅量为主：近期红色成交量占主导（用户偏好）

卖出信号检查：
  ☐ 跌破均线：跌破 5 日均线 或 跌破 20 日均线
  ☐ 均线死叉：3 日均线死叉 11 日均线
  ☐ 成交量萎缩：连续 3 天不创新高 + 量缩
  ☐ MACD 死叉：高位死叉或顶背离
  ☐ 巨量长阴：放量下跌（量 > 5 日均量 × 2）

输出：
  → 技术评分：买入信号满足数 / 5
  → 技术评级：强买点/买点/弱买点/不满足 或 强卖点/卖点/弱卖点/不满足
```

### Step 4：资金分析

调用 P18/P19 资金面部分：

```
资金面分析：

买入信号检查：
  ☐ 主力资金连续 3 日净流入
  ☐ 超大单占比 > 30%
  ☐ 北向资金连续 3 日净流入该股

卖出信号检查：
  ☐ 主力资金连续 3 日净流出
  ☐ 北向资金连续 5 日净流出该股

输出：
  → 资金评级：流入/流出/中性
  → 是否确认买入信号
  → 是否触发卖出警示
```

### Step 5：综合判断

```
综合判断逻辑：

买入判断：
  → 估值面满足（PE < 40%） AND
  → 技术面满足（≥ 3 个买入信号） AND
  → 资金面满足（主力净流入）
  → 结论：建议买入

卖出判断：
  → 硬性止损触发（亏损 ≥ 5%） → 立即止损
  → 估值警示（PE > 60%） AND 技术警示 → 分批减仓
  → 技术警示（≥ 2 个卖出信号） → 观察/减仓
  → 资金警示 + 技术警示 → 清仓

持有判断：
  → 未触发买入条件 AND 未触发卖出条件 → 继续持有/观察
```

### Step 6：仓位规划

调用 P20 仓位纪律：

```
仓位规划（如建议买入）：

1. 确认账户状态
   → 当前持仓占比
   → 现金预留
   → 单只最高仓位

2. 设定本次仓位
   → 计划总仓位：≤ 20%
   → 第一批仓位：10%
   → 第二批仓位：10%（回踩均线不破时加仓）

3. 设定止损止盈
   → 止损位：买入价 × 0.95（亏损 5%）
   → 止盈位：盈利 10% 后移动止盈至 5% 回撤

4. 确认不加仓条件
   → 第一批亏损 > 3%
   → 技术形态转弱
   → 板块热度消退
```

## 六、注意事项

1. **技术面必须满足**：估值便宜但技术弱势 ≠ 买点
2. **硬性止损优先**：触发硬性止损立即执行，不犹豫
3. **不追涨停板**：涨停后不追，等待回调确认
4. **错过买点放弃**：不做错比错过更重要
