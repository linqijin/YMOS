# Hands 模块

> 执行层：选股扫描 + 买卖信号 + 仓位规划 + 复盘统计

---

## 模块职责

Hands 是 YMOS V3 的执行层，将 Brain 的分析转化为具体可执行的操作计划：

| 职责 | SOP | 输出 |
|:---|:---|:---|
| **选股扫描** | `SOP_选股扫描.md` | 每日候选池（5-8 只） |
| **买卖信号** | `SOP_买卖信号.md` | 买入/卖出建议 + 止损位 |
| **仓位规划** | `SOP_仓位规划.md` | 分批建仓计划 + 仓位上限 |
| **复盘统计** | `SOP_复盘统计.md` | 胜率/盈亏比统计 + 系统迭代 |

---

## P 系列提示词

| 编号 | 名称 | 用途 |
|:---|:---|:---|
| P17 | 选股筛选器 | 四步筛选（政策→资金→基本面→估值） |
| P18 | 买入信号 | 三维度买入（估值+技术+资金） |
| P19 | 卖出信号 | 三维度卖出 + 硬性止损 |
| P20 | 仓位纪律 | 分批建仓 + 仓位上限 + 止损控制 |
| P21 | 复盘统计 | 胜率/盈亏比/最大回撤追踪 |

## 与其他模块协作

```
Eyes（市场洞察）
    ↓ 提供热点板块 + 资金流向
Hands（选股扫描）
    ↓ 输出候选池
Brain（策略分析）
    ↓ P2/P9/P5 分析个股
Hands（买卖信号 + 仓位规划）
    ↓ 输出操作清单
用户确认执行 → 持仓与关注（状态更新）
    ↓
Hands（复盘统计）
    ↓ 迭代优化
```
