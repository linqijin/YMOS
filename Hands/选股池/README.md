# 选股池目录

> 每日选股候选池输出目录

---

## 目录结构

```
选股池/
└── YYYY-MM/
    └── YYYY-MM-DD_选股池.md
```

---

## 文件格式

每份选股池包含：

1. **政策方向** - 2-3 个政策受益赛道
2. **资金热度** - 热门板块清单
3. **候选清单** - 5-8 只最终候选
4. **明日重点** - Top 3 重点观察
5. **排除说明** - 今日排除的股票及原因

---

## 使用方式

触发暗号 `选股一下` 后，Agent 将按照 `Hands/SOP_选股扫描.md` 执行，输出当日候选池到此目录。
