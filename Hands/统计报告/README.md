# 统计报告目录

> 每周/每月复盘统计报告输出目录

---

## 目录结构

```
统计报告/
└── YYYY-MM/
    ├── 第1周_复盘报告.md
    ├── 第2周_复盘报告.md
    ├── 第3周_复盘报告.md
    ├── 第4周_复盘报告.md
    └── 月度复盘报告.md
```

---

## 文件格式

### 每周复盘报告
- 本周交易统计
- 盈利/亏损交易分析
- 纪律执行评估
- 下周调整计划

### 每月复盘报告
- 月度统计（胜率/盈亏比/回撤/期望值）
- 最成功/最失败交易分析
- 系统迭代记录
- 下月规划

---

## 使用方式

触发暗号 `复盘一下交易` 后，Agent 将按照 `Hands/SOP_复盘统计.md` 执行，输出复盘报告到此目录。
