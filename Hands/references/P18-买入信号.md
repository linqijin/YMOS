# P18 买入信号

> 三维度共振买入：估值面（便宜）+ 技术面（趋势转强）+ 资金面（聪明钱进场）
> 适用：短线/中长线买入时机判断，输出买入建议

---

## 一、三维度买入框架

| 维度 | 核心信号 | 短线标准 | 中长线标准 |
|:---|:---|:---|:---|
| **估值面** | PE/PB 历史百分位 | < 40%（容忍度高） | < 30%（严格） |
| **技术面** | 趋势反转信号 | 放量突破 + 均线金叉 | 周线级别趋势反转 |
| **资金面** | 资金流入确认 | 主力净流入 > 30% | 北向资金连续 3 日净流入 |

**买入原则**：三维度至少满足 **2 个**，技术面必须满足。

---

## 二、估值面信号（便宜）

### 判断标准
| 指标 | 买入区间 | 说明 |
|:---|:---|:---|
| **PE 历史百分位** | < 30%（中长线）/ < 40%（短线） | 安全边际 |
| **PB 历史百分位** | < 30% | 适合周期股 |
| **PEG** | < 0.8 | 成长股买点 |

### 查询方法
- 同花顺/东方财富：个股 → F10 → 估值分析
- Tushare Pro：`daily_basic` 接口获取 PE/PB

### 输出
| 股票 | 当前 PE | 历史百分位 | 估值评级 | 是否满足买入条件 |

---

## 三、技术面信号（趋势转强）

### 短线买入信号（用户适用）
| 信号 | 标准 | 权重 |
|:---|:---|:---|
| **均线突破** | 股价站上 20 日均线且站上 3 天不跌破 | ⭐⭐⭐ |
| **均线金叉** | 3 日均线金叉 11 日均线（用户偏好） | ⭐⭐⭐ |
| **成交量放大** | > 5 日均量 × 1.5 倍 | ⭐⭐ |
| **MACD 金叉** | 零轴下方金叉或红柱放大 | ⭐⭐ |
| **红量为主** | 近期红色成交量占主导（用户偏好） | ⭐⭐ |

### 技术形态评分
| 满足信号数 | 评级 | 建议 |
|:---|:---|:---|
| ≥ 4 个 | 强买点 | 可执行 |
| 3 个 | 买点 | 分批买入 |
| 2 个 | 弱买点 | 观察等待 |
| < 2 个 | 不满足 | 放弃 |

### 输出
| 股票 | 均线状态 | 成交量状态 | MACD 状态 | 红量占比 | 技术评分 |

---

## 四、资金面信号（聪明钱进场）

### 判断标准
| 指标 | 短线标准 | 说明 |
|:---|:---|:---|
| **主力资金净流入** | 连续 3 日净流入 | 机构介入 |
| **超大单占比** | > 30% | 大资金主导 |
| **北向资金** | 连续 3 日净流入该股 | 外资认可 |
| **大宗交易溢价** | 出现溢价成交 | 强信号 |

### 查询方法
- 东方财富：个股 → 资金流向
- 同花顺：资金博弈指标

### 输出
| 股票 | 主力资金（3 日累计） | 超大单占比 | 北向资金 | 资金评级 |

---

## 五、买入实战流程

### Step 1：估值初筛
1. 查 PE/PB 历史百分位
2. 短线 < 40% 通过，中长线 < 30% 通过
3. 不通过 → 放弃或等待回调

### Step 2：技术确认
1. 检查 5 个技术信号
2. 至少满足 3 个 → 进入资金验证
3. < 3 个 → 放入观察池等待

### Step 3：资金验证
1. 查主力资金流向
2. 连续 3 日净流入 + 超大单占比 > 30% → 确认买入
3. 资金流出 → 观察等待

### Step 4：分批买入
```
第一批：信号确认当天收盘前（30% 仓位）
第二批：回踩均线不破时加仓（30% 仓位）
预留：40% 资金应对波动
```

## 六、最佳买入时间窗口

| 时间段 | 特点 | 适用场景 |
|:---|:---|:---|
| **9:30-10:00** | 资金态度最明确 | 首选，适合强势股 |
| **14:30-14:55** | 尾盘确定性高 | 次选，适合稳健入场 |
| **盘中其他时间** | 波动大 | 避免，除非有明确信号 |

### 放弃条件
- ❌ 涨停板打开后回封失败
- ❌ 错过最佳买点（如已涨 > 5%）
- ❌ 板块内无涨停股带动（孤军深入）

## 七、买入前置检查清单

执行买入前必须确认：

```markdown
## 买入检查清单

- [ ] PE 历史百分位 < 40%（短线）/ < 30%（中长线）
- [ ] 技术信号满足 ≥ 3 个
- [ ] 主力资金连续 3 日净流入
- [ ] 板块有持续性（≥3 只涨停或资金持续流入）
- [ ] 预设止损位（亏损 5-8% 无条件离场）
- [ ] 预设仓位（单只不超过账户 20-30%）
- [ ] 预设止盈位（盈利 10% 后移动止盈）
```

## 九、风险控制

**硬性止损**：
- 短线：亏损 **5%** 无条件离场
- 中长线：亏损 **8-10%** 无条件离场

**移动止盈**：
- 盈利后，止损线移至成本价（确保不亏）
- 盈利 10% 后，止盈线移至最高点回撤 5%

---

## 十、注意事项

1. **不追涨停板**（用户禁忌）
2. **错过买点宁可放弃**：不做错比错过更重要
3. **技术面必须满足**：估值便宜但技术弱势 ≠ 买点
4. **板块效应优先**：个股买点需要板块热度支撑
