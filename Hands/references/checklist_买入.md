# 检查清单：买入前

> 执行买入前必须逐项确认，任意一项不满足则放弃买入

---

## 一、估值面检查

- [ ] PE 历史百分位 < 40%（短线）/ < 30%（中长线）
- [ ] PB 历史百分位 < 30%（可选）
- [ ] PEG < 1（成长股，可选）

**估值面至少满足 1 项**

---

## 二、技术面检查

- [ ] 股价站上 20 日均线且站上 3 天不跌破
- [ ] 3 日均线金叉 11 日均线（用户偏好）
- [ ] 成交量 > 5 日均量 × 1.5 倍
- [ ] MACD 金叉或红柱放大
- [ ] 近期红色成交量占主导（用户偏好）

**技术面至少满足 3 项（技术评分 ≥ 买点）**

---

## 三、资金面检查

- [ ] 主力资金连续 3 日净流入
- [ ] 超大单占比 > 30%
- [ ] 北向资金连续 3 日净流入该股（可选）

**资金面至少满足 1 项**

---

## 四、板块效应检查

- [ ] 所属板块成交量 > 20 日均量线 × 1.3
- [ ] 同题材涨停股 ≥ 3 只
- [ ] 板块热度评级 ≥ 中

**板块效应至少满足 2 项**

---

## 五、仓位检查

- [ ] 本次计划仓位 ≤ 20%
- [ ] 账户现金预留 ≥ 30%
- [ ] 单只股票仓位不超过 30%（含本次）
- [ ] 当前持仓数量 ≤ 5 只

**仓位检查全部满足**

---

## 六、止损预设检查

- [ ] 已确定止损位：买入价 × 0.95（亏损 5%）
- [ ] 已确定技术止损位：5 日均线 / 20 日均线
- [ ] 已确定止盈策略：盈利 10% 后移动止盈

**止损预设必须全部确定**

---

## 七、禁忌检查

- [ ] 非 ST 股票
- [ ] 不追涨停板（涨停股放入观察池）
- [ ] 近期无大规模解禁/减持公告
- [ ] 股价在 20 日均线上方运行

**禁忌检查全部满足**

---

## 八、时间窗口检查

- [ ] 当前时间在最佳买入窗口（9:30-10:00 或 14:30-14:55）
- [ ] 非盘中随意买入

**时间窗口满足**

---

## 九、心理检查

- [ ] 不是因为 FOMO（害怕错过）而买入
- [ ] 不是因为报复性交易（止损后想扳回）而买入
- [ ] 不是因为别人推荐而买入（有独立判断）
- [ ] 今日止损次数 < 2 次

**心理状态正常**

---

## 十、最终确认

```
买入确认：
  → 估值面：满足 ☐ 不满足 ☐
  → 技术面：满足 ☐ 不满足 ☐（≥ 3 项）
  → 资金面：满足 ☐ 不满足 ☐
  → 板块效应：满足 ☐ 不满足 ☐
  → 仓位检查：满足 ☐ 不满足 ☐
  → 止损预设：满足 ☐ 不满足 ☐
  → 禁忌检查：满足 ☐ 不满足 ☐
  → 时间窗口：满足 ☐ 不满足 ☐
  → 心理检查：满足 ☐ 不满足 ☐

结论：
  → 全部满足 → 执行买入（分两批）
  → 任意一项不满足 → 放弃买入或等待条件满足
```

---

## 十一、分批买入计划

### 第一批执行确认
- [ ] P18 买入信号确认完毕
- [ ] 当前时间在最佳窗口（9:30-10:00）
- [ ] 执行第一批仓位（计划总仓位的 50%）

### 第二批执行确认
- [ ] 第一批买入后未亏损 > 3%
- [ ] 回踩均线不破 或 尾盘确认强势
- [ ] 技术形态未转弱
- [ ] 板块热度维持
- [ ] 执行第二批仓位（计划总仓位的 50%）

---

## 十二、放弃买入条件

触发以下任意一条 → 放弃买入：

- ❌ 技术面 < 3 项满足
- ❌ 板块热度消退（无涨停股带动）
- ❌ 主力资金转为流出
- ❌ 今日已止损 2 次
- ❌ 错过最佳买点（已涨 > 5%）
- ❌ 涨停板打开后回封失败
- ❌ FOMO 或报复性交易心态
