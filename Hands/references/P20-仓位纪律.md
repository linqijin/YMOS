# P20 仓位纪律

> 分批建仓 + 仓位上限 + 日内止损控制
> 适用：短线交易仓位管理，防止单票过重、做T失败不断补仓

---

## 一、仓位管理核心原则

| 原则 | 内容 | 原因 |
|:---|:---|:---|
| **单次控制** | 每次开仓 ≤ 可用资金的 30-40% | 留出补仓和应对波动空间 |
| **上限约束** | 单只股票仓位 ≤ 账户总资金的 20-30% | 防止单票过重 |
| **分批建仓** | 分两批买入，不一次性满仓 | 降低风险，验证判断 |
| **止损铁律** | 连续止损 2 次 → 当日停止交易 | 防止情绪化交易 |

---

## 二、账户规模与仓位配置

| 账户规模 | 单只股票上限 | 同时持仓数量 | 现金预留 |
|:---|:---|:---|:---|
| **10 万以下** | 20%-30% | 2-3 只 | ≥ 20% |
| **10-50 万** | 15%-20% | 3-5 只 | ≥ 25% |
| **50 万以上** | 10%-15% | 4-6 只 | ≥ 30% |

**用户当前情况**：
- 资金占比 80%（偏高）
- 单只上限 50%（过高，需降至 20-30%）
- 建议：预留 30% 现金，降低单只仓位

## 三、分批建仓方法

### 标准分批流程
以计划投入总资金的 20% 为例：

| 批次 | 仓位比例 | 触发条件 | 时间窗口 |
|:---|:---|:---|:---|
| **第一批** | 10% | P18 信号确认 | 9:30-10:00（首选）或 14:30-14:55 |
| **第二批** | 10% | 回踩均线不破 或 尾盘确认强势 | 当日尾盘或次日早盘 |

### 分批建仓示意
```
Day 1 上午：
  → P18 信号确认 → 买入第一批 10%

Day 1 下午：
  → 回踩均线不破 → 加仓第二批 10%
  → 或尾盘确认强势 → 加仓

Day 2：
  → 如 Day 1 未加仓，观察次日早盘确认 → 加仓第二批
  → 如跌破均线 → 不加仓，考虑止损第一批
```

### 不加仓条件
- ❌ 第一批买入后下跌超过 3%
- ❌ 技术形态转弱（跌破均线）
- ❌ 板块热度消退（无涨停股带动）
- ❌ 主力资金转为流出

## 四、止损控制纪律

### 单笔止损
| 场景 | 止损标准 | 执行 |
|:---|:---|:---|
| **短线买入后** | 亏损 ≥ 5% | 无条件离场 |
| **低开超 3%** | 2 分钟内未翻红 | 立即止损 |
| **跌破 5 日均线** | 2 日内未收回 | 减仓 50% |
| **跌破 20 日均线** | 3 日内未收回 | 清仓 |

### 日内止损铁律
```
**当天连续止损 2 次 → 立即停止当天所有交易**
```

这是防止情绪化交易的最重要纪律。连续亏损说明：
- 要么当天市场环境不适合你的系统
- 要么你的判断已经出现了偏差

停下来复盘，而不是继续交易试图「扳回来」。

## 五、做T失败处理规则

### 用户痛点：做T容易做成补仓
**问题表现**：
- 做T买入后下跌 → 不止损，反而加仓
- 导致仓位越来越重，偏离原计划

### 解决方案
| 场景 | 正确操作 | 错误操作 |
|:---|:---|:---|
| **做T买入后盈利** | 按计划卖出原仓位的一部分 | 贪婪不卖 |
| **做T买入后小亏（< 3%）** | 当日收盘前止损卖出 | 加仓摊成本 |
| **做T买入后大亏（≥ 3%）** | 立即止损，当日不再做T | 不断补仓 |

### 做T前提条件
- [ ] 持仓已有盈利（成本上方）
- [ ] 当日波动足够（振幅 > 3%）
- [ ] 技术形态未破坏（均线支撑）
- [ ] 预设做T止损位（亏损 > 2% 立即止损）

**不满足条件 → 不做T**

## 六、仓位上限硬约束

### 单只股票仓位控制
| 仓位比例 | 风险等级 | 操作建议 |
|:---|:---|:---|
| **< 15%** | 低风险 | 正常持有 |
| **15%-20%** | 中风险 | 警惕，不加仓 |
| **20%-30%** | 高风险 | 不再加仓，触发卖出条件先减仓 |
| **> 30%** | 极高风险 | 必须减仓至 20% 以下 |

### 用户约束
- **硬性上限**：单只股票 ≤ 30%（从当前 50% 降低）
- **触发减仓**：仓位 > 20% + 技术警示 → 减仓至 15%

## 七、加减仓决策表

| 场景 | 仓位状态 | 操作 |
|:---|:---|:---|
| **盈利 + 技术强** | < 15% | 可加仓至 20% |
| **盈利 + 技术弱** | 任意 | 不加仓，观察 |
| **亏损 + 技术强** | < 10% | 观察不加仓 |
| **亏损 + 技术弱** | 任意 | 止损，不加仓 |
| **连续盈利 3 天** | 任意 | 卖出 50% 锁利 |
| **仓位 > 20%** | 任意 | 不再加仓 |
| **连续止损 2 次** | 任意 | 当日停止交易 |

## 九、仓位管理检查清单

### 买入前检查
```markdown
- [ ] 本次计划仓位 ≤ 20%
- [ ] 分两批买入，不一次性满仓
- [ ] 预设止损位（亏损 5%）
- [ ] 预设不加仓条件
- [ ] 账户现金预留 ≥ 30%
```

### 持仓期间检查（每日）
```markdown
- [ ] 单只仓位是否超过 20%
- [ ] 是否触发止损条件
- [ ] 是否满足加仓条件（仓位 < 15% + 技术强）
- [ ] 今日是否已止损 2 次（触发则停止交易）
```

### 卖出后检查
```markdown
- [ ] 记录本次交易盈亏
- [ ] 检查仓位是否降至合理水平
- [ ] 反思是否违反仓位纪律
```

## 十、用户特定强化

### 问题：仓位管理决定盈亏上限
**历史教训**：涨停板抓到但仓位小，盈利有限

**解决方案**：
- 选股阶段识别涨停潜力股 → 提高计划仓位上限至 30%
- 但必须满足 P17 选股标准 + P18 强买点（≥ 4 个信号）
- 涨停后不追，等待回调确认再加仓

### 问题：做T失败不断补仓
**历史教训**：想做T降成本，但经常做成补仓

**解决方案**：
- **做T必须预设止损**：亏损 > 2% 立即止损
- **做T失败当日处理**：收盘前止损卖出，不留过夜
- **不补仓摊成本**：补仓必须满足 P18 新买入信号

---

## 十一、注意事项

1. **仓位纪律不可绕过**：触发止损立即执行，不幻想
2. **连续止损停下来**：连续 2 次止损 → 当日停止，复盘反思
3. **现金预留是安全垫**：预留 30% 应对突发和补仓机会
4. **仓位上限是硬约束**：单只 ≤ 30%，超过必须减仓
