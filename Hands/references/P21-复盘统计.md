# P21 复盘统计

> 交易复盘与系统迭代：胜率/盈亏比/最大回撤追踪
> 适用：每周/每月复盘，识别问题并优化系统

---

## 一、复盘统计框架

| 模块 | 核心指标 | 目标参考值 | 统计周期 |
|:---|:---|:---|:---|
| **胜率** | 盈利交易次数 / 总交易次数 | > 55% | 每周/月 |
| **盈亏比** | 平均盈利 / 平均亏损 | > 1.5 | 每周/月 |
| **最大回撤** | 账户净值高点到低点最大跌幅 | < 15% | 每月 |
| **期望值** | 胜率 × 平均盈利 - (1-胜率) × 平均亏损 | 正值 | 每月 |

## 三、每日复盘流程

### 收盘后 15 分钟
```
Step 1：更新持仓状态
  → 记录每只持仓今日涨跌幅
  → 检查是否触发 P19 卖出条件

Step 2：记录今日交易
  → 如有买卖，填写交易记录模板
  → 标记是否违反纪律

Step 3：扫描候选池
  → 更新 P17 选股候选池状态
  → 确认明日重点观察标的
```

## 四、每周复盘流程

### 周末 30 分钟
```
Step 1：统计本周指标
  → 计算胜率、盈亏比
  → 记录本周最大单笔盈亏

Step 2：分析盈利交易
  → 识别共性：哪些条件成功率高
  → 总结有效模式

Step 3：分析亏损交易
  → 识别共性：哪些信号失效
  → 检查是否违反纪律

Step 4：系统微调
  → 针对问题调整 1-2 条规则
  → 记录调整内容

Step 5：下周计划
  → 确定重点关注板块
  → 设定下周仓位上限
```

## 五、每月复盘流程

### 月末 1 小时
```
Step 1：统计月度指标
  → 胜率、盈亏比、最大回撤
  → 计算期望值

Step 2：对比目标值
  → 是否达标？差距多少？

Step 3：深度分析
  → 识别最成功的 3 笔交易
  → 识别最失败的 3 笔交易
  → 分析成功/失败原因

Step 4：系统迭代
  → 根据统计结果调整规则
  → 记录迭代版本

Step 5：下月规划
  → 调整仓位配置
  → 调整止损/止盈参数
```

## 六、统计指标详解

### 1. 胜率（Win Rate）
```
胜率 = 盈利交易次数 / 总交易次数

目标：> 55%

判断：
  胜率 < 50% → 买入标准过宽或止损过严
  胜率 > 70% → 可能止盈过早（盈亏比可能低）
```

### 2. 盈亏比（Profit/Loss Ratio）
```
盈亏比 = 平均盈利金额 / 平均亏损金额

目标：> 1.5

判断：
  盈亏比 < 1.0 → 止盈过早或止损过宽
  盈亏比 > 2.0 → 系统优秀，可适当放宽买入标准
```

### 3. 最大回撤（Max Drawdown）
```
最大回撤 = (账户净值高点 - 账户净值低点) / 账户净值高点

目标：< 15%

判断：
  回撤 > 20% → 仓位过重或止损不严
  回撤 < 10% → 风控良好
```

### 4. 期望值（Expected Value）
```
期望值 = 胜率 × 平均盈利 - (1-胜率) × 平均亏损

目标：正值

判断：
  期望值 < 0 → 系统亏损，需调整
  期望值 > 0 → 系统盈利，可持续
```

## 七、问题诊断表

根据统计结果识别问题：

| 问题表现 | 可能原因 | 优化方向 |
|:---|:---|:---|
| **胜率高但盈亏比低** | 止盈过早或止损过宽 | 放宽止盈条件，收紧止损 |
| **盈亏比高但胜率低** | 买点选择过于激进 | 提高 P18 买入标准（≥ 4 个信号） |
| **最大回撤过大** | 仓位过重或止损不严 | 降低单只仓位，严格执行 P19 止损 |
| **期望值为负** | 系统整体亏损 | 全面复盘，暂停交易调整系统 |
| **连续亏损后出现大亏** | 情绪化交易 | 严格执行「2 次止损后暂停」规则 |
| **做T成功率低** | 做T条件不明确 | 强化做T前提条件检查 |

## 八、系统迭代流程

```
第 1 步：每周统计胜率、盈亏比、最大回撤
第 2 步：分析亏损交易，找出共性原因
第 3 步：针对问题调整 1-2 条规则
第 4 步：用调整后的规则交易 2 周
第 5 步：对比调整前后的统计数据
第 6 步：保留有效改进，继续迭代
```

| V1.1 | 止损从 8% 改为 5% | 回撤过大 | 2 周 | 胜率提升 X%，回撤降低 X% |

## 十一、用户特定强化

### 问题：无完整投资系统
**历史教训**：缺少系统化复盘，无法识别问题

**解决方案**：
- 每周执行复盘流程，统计胜率/盈亏比
- 根据数据调整系统，不凭感觉

### 问题：卖出无硬性纪律
**历史教训**：触发止损不执行，幻想反弹

**解决方案**：
- 复盘时统计纪律违规率
- 违规率 > 20% → 需强化执行机制

---

## 十二、注意事项

1. **用数据说话**：不凭感觉判断系统好坏，看统计指标
2. **小步迭代**：每次只调整 1-2 条规则，测试 2 周再评估
3. **暂停交易调整**：期望值为负时暂停交易，系统调整后再恢复
4. **记录每笔交易**：没有记录就无法复盘，必须养成记录习惯
