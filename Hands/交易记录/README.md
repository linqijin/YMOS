# 交易记录目录

> 每笔交易记录输出目录

---

## 目录结构

```
交易记录/
└── YYYY-MM/
    ├── YYYY-MM-DD_交易日志.md
    └── 第X周_复盘报告.md
```

---

## 文件格式

### 每日交易日志
- 今日交易记录（买入/卖出）
- 持仓状态更新
- 候选池更新
- 明日计划

### 每周复盘报告
- 本周统计（胜率/盈亏比）
- 盈利交易分析
- 亏损交易分析
- 纪律执行评估
- 下周调整

---

## 使用方式

交易完成后记录到 `YYYY-MM-DD_交易日志.md`，周末触发 `复盘一下交易` 生成周复盘报告。
