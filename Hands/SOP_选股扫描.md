# SOP 选股扫描

> 每日选股流程：政策定方向 → 资金判热度 → 基本面选优 → 估值定时机
> 触发暗号：`选股一下` / `今日选股`

---

## 一、流程概述

| Step | 动作 | 时间窗口 | 输出 |
|:---|:---|:---|:---|
| 1 | 政策方向扫描 | 收盘后 5 分钟 | 2-3 个政策受益赛道 |
| 2 | 资金热度扫描 | 收盘后 5 分钟 | 热门板块清单 |
| 3 | 个股筛选 | 收盘后 10 分钟 | 每板块 3-5 只候选 |
| 4 | 估值时机判断 | 收盘后 5 分钟 | 估值评级 |
| 5 | 候选池输出 | 收盘后汇总 | 5-8 只最终候选 |
| 6 | 次日重点确认 | 开盘前 10 分钟 | 3-5 只重点观察 |

---

## 二、前置条件

执行前必须：
1. 已读取 `持仓与关注/当前关注方向与投资偏好.md`
2. 已获取当日板块涨幅榜和成交量排名数据
3. 已获取当日涨停板归类数据

---

## 三、详细流程

### Step 1：政策方向扫描

```
信息源：
  → 财联社、华尔街见闻、同花顺"涨停原因"
  → 政策关键词追踪

关键词（当前重点关注）：
  → 新质生产力、自主可控、设备更新
  → 数字经济、人工智能、新能源
  → 电力、电网、液冷（用户关注板块）

输出：
  → 锁定 2-3 个政策受益赛道
  → 记录每个赛道的催化事件

格式：
| 赛道 | 政策关键词 | 近期催化事件 | 相关涨停股 |
```

### Step 2：资金热度扫描

```
数据源：
  → 同花顺/东方财富：板块涨幅榜 + 成交量排名
  → 板块资金流向功能

筛选标准（短线）：
  → 板块成交量 > 20 日均量线 × 1.3
  → 同题材涨停股 ≥ 3 只
  → 北向资金连续 3 日净流入板块（如有数据）

黄金窗口回顾（盘中）：
  → 9:25-10:00 该板块涨停股数量变化
  → 从 2-3 只扩充至 7-8 只 = 热度爆发态势

输出：
| 板块 | 成交量状态 | 涨停数 | 北向资金 | 热度评级 |
|:---|:---|:---|:---|:---|
| XX | 放量/缩量 | XX | 流入/流出 | 高/中/低 |
```

### Step 3：个股筛选

```
在每个热门板块中筛选个股：

基本面筛选（短线放宽）：
  → ROE ≥ 10%
  → 净利润增速 ≥ 15%
  → 流通市值：50-300 亿元
  → 换手率：5%-15%

排除项：
  → 换手率 < 5%（冷门）
  → 近期大规模解禁/减持公告
  → ST 股票（用户禁忌）
  → 股价在 20 日均线下方运行（弱势）

技术形态筛选：
  → 放量突破
  → 均线多头排列
  → MACD 金叉

输出：
每板块筛选 3-5 只技术形态最强个股
| 股票 | 代码 | 板块 | ROE | 流通市值 | 换手率 | 技术形态 |
```

### Step 4：估值时机判断

```
对筛选出的个股进行估值判断：

估值标准（短线）：
  → PE 历史百分位 < 40%（买入区间）
  → PB 历史百分位 < 30%
  → PEG < 1（如有数据）

数据源：
  → 同花顺/东方财富：F10 → 估值分析
  → Tushare Pro（如有 Token）

输出：
| 股票 | 当前 PE | 历史百分位 | 估值评级 |
|:---|:---|:---|:---|
| XX | XX | XX% | 低估/合理/偏高 |
```

### Step 5：候选池输出

```
综合四步筛选，输出当日候选池：

候选池标准：
  → 四步至少满足三步
  → 资金热度 + 技术形态必须满足
  → 估值容忍度可放宽

输出格式：
见下方「候选池输出格式」
```

### Step 6：次日重点确认

```
次日开盘前（8:30-9:15）执行：

1. 查看隔夜重大新闻和公告
   → 影响候选池中个股的新闻
   → 板块政策变化

2. 观察 9:15-9:25 集合竞价异动
   → 候选股竞价表现
   → 板块整体竞价强弱

3. 确定当日重点 3-5 只标的
   → 竞价强势者优先
   → 有利好消息者优先
   → 技术形态最优者优先

盘中（9:30-10:00）：
   → 观察重点标的表现
   → 确认资金态度
   → 决定是否执行买入（调用 SOP_买卖信号）
```

## 六、权重调整（用户短线风格）

用户为**短线交易者（几天周期）**，四步权重调整：

| 步骤 | 标准权重 | 用户权重 | 说明 |
|:---|:---|:---|:---|
| 政策定方向 | 第二 | 第二 | 辅助验证 |
| 资金判热度 | 第一 | **第一** | 短线核心 |
| 基本面选优 | 第四 | **放宽** | ROE ≥ 10% 即可 |
| 估值定时机 | 第三 | **放宽** | PE < 40% 即可 |

**用户核心判断顺序**：资金热度 → 技术形态 → 板块效应 → 估值/基本面辅助

---

## 七、注意事项

1. **资金热度必须满足**：板块成交量放大 + 涨停股 ≥ 3 只
2. **技术形态必须满足**：至少 2 个买入信号
3. **不追涨停板**：涨停股放入观察池，等待回调确认
4. **错过最佳买点放弃**：候选股已涨 > 5%，移除或降级
5. **每日更新候选池**：移除不符合条件的，新增符合条件的

## 八、与现有模块协作

```
选股扫描流程协作：

Eyes（市场洞察）
  ↓ 提供热点板块 + 资金流向数据
Hands（选股扫描）
  ↓ 输出候选池
Brain（策略分析）
  ↓ 对候选股执行 P2/P9/P5 分析
Hands（买卖信号）
  ↓ 输出买入建议 + 止损位
用户确认执行
```

调用关系：
- `选股一下` → 先检查是否有今日市场洞察报告
- 如无 → 提示用户先执行 `跑一下市场洞察`
- 如有 → 直接使用洞察报告中的板块数据
