# SOP 复盘统计

> 交易复盘与系统迭代
> 触发暗号：`复盘一下交易` / `交易复盘`

---

## 一、流程概述

| Step | 动作 | 时间窗口 | 输出 |
|:---|:---|:---|:---|
| 1 | 交易记录汇总 | 月末/周末 | 本期所有交易清单 |
| 2 | 统计指标计算 | 月末/周末 | 胜率/盈亏比/回撤 |
| 3 | 盈利交易分析 | 月末/周末 | 成功共性总结 |
| 4 | 亏损交易分析 | 月末/周末 | 失败共性总结 |
| 5 | 纪律执行评估 | 月末/周末 | 违规率统计 |
| 6 | 系统迭代建议 | 月末/周末 | 调整规则建议 |
| 7 | 复盘报告输出 | 月末/周末 | 复盘报告文件 |

## 三、详细流程

### Step 1：交易记录汇总

```
读取本期所有交易日志：
  → Hands/交易记录/YYYY-MM/YYYY-MM-DD_交易日志.md

汇总交易清单：
| 序号 | 股票 | 买入日期 | 买入价格 | 卖出日期 | 卖出价格 | 持仓天数 | 盈亏% |
|:---|:---|:---|:---|:---|:---|:---|:---|

统计：
  → 总交易次数
  → 盈利次数
  → 亏损次数
  → 平均持仓天数
```

### Step 2：统计指标计算

```
调用 P21 复盘统计：

计算核心指标：
  1. 胜率 = 盈利交易次数 / 总交易次数
     目标：> 55%

  2. 盈亏比 = 平均盈利金额 / 平均亏损金额
     目标：> 1.5

  3. 最大回撤 = (账户净值高点 - 账户净值低点) / 账户净值高点
     目标：< 15%

  4. 期望值 = 胜率 × 平均盈利 - (1-胜率) × 平均亏损
     目标：正值

输出：
| 指标 | 本期值 | 目标值 | 是否达标 |
|:---|:---|:---|:---|
| 胜率 | XX% | > 55% | ☐ |
| 盈亏比 | XX | > 1.5 | ☐ |
| 最大回撤 | XX% | < 15% | ☐ |
| 期望值 | XX | 正值 | ☐ |
```

### Step 3：盈利交易分析

```
识别盈利交易共性：

分析维度：
  → 买入依据：哪些 P18 条件成功率高
  → 板块特征：哪些板块盈利多
  → 技术形态：哪些形态盈利多
  → 持仓时间：盈利交易的平均持仓天数

输出：
| 股票 | 盈亏% | 买入依据 | 板块 | 技术形态 | 成功原因 |
|:---|:---|:---|:---|:---|:---|

盈利交易共性总结：
  → [有效买入条件]
  → [有效板块类型]
  → [有效技术形态]
```

### Step 4：亏损交易分析

```
识别亏损交易共性：

分析维度：
  → 失败原因：买入信号失效 / 止损未执行 / 市场突变
  → 违纪情况：是否违反 P20 仓位纪律或 P19 止损纪律
  → 板块特征：哪些板块亏损多
  → 技术形态：哪些形态亏损多

输出：
| 股票 | 盈亏% | 失败原因 | 违纪 | 板块 | 技术形态 |
|:---|:---|:---|:---|:---|:---|

亏损交易共性总结：
  → [失效买入条件]
  → [高危板块类型]
  → [高危技术形态]
  → [违纪情况统计]
```

### Step 5：纪律执行评估

```
统计纪律执行情况：

检查项：
  → 固定止损 5% 是否执行
  → 仓位上限 30% 是否遵守
  → 连续止损暂停是否执行
  → 不加仓条件是否遵守
  → 做T失败是否止损而非补仓

输出：
| 纪律项 | 应执行次数 | 实执行次数 | 违规次数 | 违规率 |
|:---|:---|:---|:---|:---|
| 固定止损 5% | XX | XX | XX | XX% |
| 仓位上限 30% | XX | XX | XX | XX% |
| 连续止损暂停 | XX | XX | XX | XX% |
| 不加仓条件 | XX | XX | XX | XX% |

评估：
  → 违规率 > 20% → 需强化执行机制
  → 违规率 < 10% → 执行良好
```

### Step 6：系统迭代建议

```
调用 P21 问题诊断表：

根据统计结果识别问题：
| 问题表现 | 可能原因 | 优化方向 |
|:---|:---|:---|

提出迭代建议：
  → 买入标准调整
  → 卖出标准调整
  → 仓位参数调整
  → 止损/止盈参数调整

迭代原则：
  → 每次只调整 1-2 条规则
  → 测试周期：2 周
  → 测试后对比数据评估效果
```

### Step 7：复盘报告输出

```
整合以上内容，输出复盘报告：
见下方「复盘报告输出格式」
```

## 六、注意事项

1. **用数据说话**：不凭感觉判断系统好坏
2. **小步迭代**：每次只调整 1-2 条规则
3. **暂停交易调整**：期望值为负时暂停交易
4. **记录每笔交易**：没有记录就无法复盘

## 七、用户特定强化

### 问题：无完整投资系统
**解决方案**：
- 每周执行复盘，统计胜率/盈亏比
- 根据数据调整系统，不凭感觉

### 问题：卖出无硬性纪律
**解决方案**：
- 复盘时统计纪律违规率
- 违规率 > 20% → 需强化执行机制
