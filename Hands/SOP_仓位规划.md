# SOP 仓位规划

> 仓位分配与止损设定
> 触发暗号：`规划仓位 [ticker]`

---

## 一、流程概述

| Step | 动作 | 输入 | 输出 |
|:---|:---|:---|:---|
| 1 | 账户状态检查 | 持仓_状态机 + 当前偏好 | 当前仓位分布 |
| 2 | 仓位上限计算 | P20 仓位纪律 | 本次可用仓位 |
| 3 | 分批建仓规划 | P20 分批方法 | 第一批/第二批计划 |
| 4 | 止损止盈设定 | P19/P20 止损规则 | 止损位/止盈位 |
| 5 | 不加仓条件设定 | P20 不加仓规则 | 触发条件清单 |
| 6 | 执行计划输出 | 整合以上内容 | 完整仓位规划 |

---

## 二、前置条件

执行前必须：
1. 已读取 `持仓与关注/持仓_状态机.md`
2. 已读取 `持仓与关注/当前关注方向与投资偏好.md`
3. 已确定目标股票的买入意向（通过 SOP_买卖信号 分析）

---

## 三、详细流程

### Step 1：账户状态检查

```
读取文件：
  → 持仓与关注/持仓_状态机.md
  → 持仓与关注/当前关注方向与投资偏好.md

检查项目：
  → 账户总资金（如有记录）
  → 当前持仓总占比
  → 现金预留比例
  → 每只持仓仓位占比
  → 单只最高仓位

对比目标值：
| 项目 | 当前值 | 目标值 | 是否超标 |
|:---|:---|:---|:---|
| 持仓占比 | XX% | ≤ 70% | ☐ |
| 现金预留 | XX% | ≥ 30% | ☐ |
| 单只最高 | XX% | ≤ 30% | ☐ |
```

### Step 2：仓位上限计算

```
调用 P20 仓位纪律：

计算本次可用仓位：
  → 账户规模档位：10 万以下 / 10-50 万 / 50 万以上
  → 单只上限：20%-30%（根据档位）
  → 当前该股仓位：0%（首次买入）或 XX%（加仓）
  → 本次最大可用仓位：单只上限 - 当前仓位

用户约束：
  → 单只上限：30%（从当前 50% 降至 30%）
  → 如当前仓位 > 20% → 不建议加仓

输出：
| 项目 | 值 |
|:---|:---|
| 单只上限 | 30% |
| 当前仓位 | XX% |
| 本次最大可用 | XX% |
| 建议本次仓位 | ≤ 20% |
```

### Step 3：分批建仓规划

```
调用 P20 分批建仓方法：

标准分批流程：
| 批次 | 仓位比例 | 触发条件 | 时间窗口 |
|:---|:---|:---|:---|
| 第一批 | 50% | P18 信号确认 | 9:30-10:00（首选）|
| 第二批 | 50% | 回踩均线不破 或 尾盘确认强势 | 当日尾盘或次日早盘 |

示例（计划总仓位 20%）：
  → 第一批：10%
  → 第二批：10%

确认第一批触发条件：
  → P18 买入信号满足 ≥ 3 个
  → 技术评分 ≥ 买点
  → 最佳时间窗口：9:30-10:00

确认第二批触发条件：
  → 第一批买入后，回踩均线不破
  → 或尾盘确认强势（涨幅维持）
  → 或次日早盘确认强势

确认不加仓条件：
  → 第一批亏损 > 3%
  → 技术形态转弱（跌破均线）
  → 板块热度消退
  → 主力资金转为流出
```

### Step 4：止损止盈设定

```
调用 P19/P20 止损规则：

固定止损：
  → 短线：亏损 ≥ 5% 无条件离场
  → 止损位 = 买入价 × 0.95

技术止损：
  → 跌破 5 日均线且 2 日未收回 → 减仓 50%
  → 跌破 20 日均线且 3 日未收回 → 清仓

移动止盈：
  → 盈利 0-10%：止损线在成本价（确保不亏）
  → 盈利 > 10%：止盈线移至最高点回撤 5%
  → 盈利 > 20%：止盈线移至最高点回撤 8%

输出：
| 止损类型 | 触发条件 | 操作 |
|:---|:---|:---|
| 固定止损 | 亏损 ≥ 5% | 全部清仓 |
| 技术止损 | 跌破 5 日均线 | 减仓 50% |
| 技术止损 | 跌破 20 日均线 | 全部清仓 |
| 移动止盈 | 盈利 > 10% | 止盈线移至回撤 5% |
```

### Step 5：不加仓条件设定

```
调用 P20 不加仓规则：

设定不加仓条件清单：
  ☐ 第一批买入后亏损 > 3%
  ☐ 技术形态转弱（跌破均线）
  ☐ 板块热度消退（无涨停股带动）
  ☐ 主力资金转为流出
  ☐ 仓位已达到上限（20%）

触发任意一条 → 不执行第二批加仓
```

### Step 6：执行计划输出

```
整合以上内容，输出完整仓位规划：
见下方「仓位规划输出格式」
```

## 六、注意事项

1. **仓位上限硬约束**：单只 ≤ 30%，超过必须减仓
2. **分批建仓不跳过**：不一次性满仓，降低风险
3. **止损预设必须**：买入前必须确定止损位
4. **连续止损暂停**：当天止损 2 次 → 停止交易

---

## 七、用户特定强化

### 问题：做T容易做成补仓
**解决方案**：
- 做T必须预设止损：亏损 > 2% 立即止损
- 做T失败当日处理：收盘前止损，不补仓
- 仓位规划中明确做T失败退出规则

### 问题：仓位管理决定盈亏上限
**解决方案**：
- 涨停潜力股识别后 → 计划仓位上限至 30%
- 但必须满足 P18 强买点（≥ 4 个信号）
- 涨停后不追，等待回调确认再加仓
