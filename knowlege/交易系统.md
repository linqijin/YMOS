一个完整的短线交易系统包含以下五个模块：

|模块|核心问题|输出结果|
|---|---|---|
|**① 信息源**|从哪里获取可靠的股票信息？|每日观察池|

## 二、模块①：信息源——从哪里获取股票信息

短线交易的信息获取，核心是**捕捉资金动向和市场情绪**，而不是研究基本面财报。

### 2.1 每日必看的三个信息维度

|维度|具体内容|获取渠道|关注重点|
|---|---|---|---|
|**资金流向**|板块成交量排名、个股主力资金净流入/流出|同花顺、东方财富、通达信的"板块排行"和"资金流向"功能|连续3日资金流入的板块|
|**热点题材**|政策新闻、行业动态、涨停股题材归类|财联社、华尔街见闻、同花顺"涨停原因"|出现3只以上涨停股的题材|
|**技术形态**|放量突破、均线多头排列、MACD金叉等|交易软件的"条件选股"功能|符合技术买点的个股|

### 2.2 资金观察的核心指标

短线高手最看重的三个核心逻辑是：**成交量、板块效应、高低切换**[](https://mf.bigquant.com/wiki/doc/Q2ArGXcdxl)。

**① 成交量是唯一的真相**

- 判断方法：观察板块指数成交量是否显著超过20日均量线
    
- 如果某板块成交量连续3-5日维持在20日均量线以上，说明机构资金正在持续涌入该领域[](https://mf.bigquant.com/wiki/doc/Q2ArGXcdxl)
    
- 这比看个股涨幅更重要，因为成交量代表了资金的"共识强度"
    

**② 板块效应捕捉爆发力**

- 黄金观察窗口：每日9:25集合竞价结束到10:00之间
    
- 若9:25某板块已有2-3只涨停，到10:00扩充至7-8只，说明该板块进入"热度爆发态势"[](https://mf.bigquant.com/wiki/doc/Q2ArGXcdxl)
    
- 这种爆发力意味着次日大概率有溢价
    

**③ 高低切换识别节奏**

- 当高位标杆股开始断板、砸盘时，资金会迅速流向低位潜力股[](https://mf.bigquant.com/wiki/doc/Q2ArGXcdxl)
    
- 高手在市场恐慌时看到的不是风险，而是资金切换的节拍
    

### 2.3 信息整理流程（每日30分钟）

text

收盘后（15-20分钟）：
1. 查看板块涨幅榜和成交量排名 → 记录前5名热点板块
2. 查看涨停板归类 → 记录有3只以上涨停的题材
3. 使用条件选股筛选技术形态（放量突破、均线金叉等）
4. 将符合条件的股票加入"观察池"
次日开盘前（10-15分钟）：
5. 查看隔夜重大新闻和公告
6. 观察9:15-9:25集合竞价的异动情况
7. 确定当日重点关注的3-5只标的

## 三、模块②：选股规范——如何筛选短线标的

结合之前的四步框架，针对短线特点进行适配：

### 3.1 短线选股的四条核心标准

|标准|具体条件|说明|
|---|---|---|
|**资金热度**|所属板块成交量 > 20日均量线 × 1.3|确保有增量资金介入[](https://mf.bigquant.com/wiki/doc/Q2ArGXcdxl)|
|**技术形态**|① 股价站上20日均线且均线向上  <br>② 成交量放大（>5日均量1.5倍）  <br>③ MACD金叉或红柱放大|至少满足2条[](https://m.163.com/dy/article/KNRJCVI205568W0A.html)|
|**流通市值**|50-300亿元|太小的容易被操纵，太大的弹性不足|
|**换手率**|5%-15%之间|低于5%活跃度不够，高于15%过热[](https://m.hexun.com/news/2025-09-12/221310398.html)|

### 3.2 需要排除的股票

- 换手率低于5%的冷门股[](https://m.hexun.com/news/2025-09-12/221310398.html)
    
- 股价在20日均线下方运行的弱势股
    
- 近期有大规模解禁或减持公告的
    
- ST板块和问题股
    

### 3.3 选股流程示例

text

每日收盘后：
Step 1：用板块成交量和涨幅榜筛选出3-5个热门板块
Step 2：在每个板块中筛选出技术形态最强的3-5只个股
Step 3：剔除换手率<5%或>15%的股票
Step 4：将剩余的5-8只股票加入"观察池"
Step 5：次日开盘后观察15分钟，确认资金态度后决定是否交易

## 四、模块③：买卖体系——何时买入、何时卖出

### 4.1 买入规则

短线交易的买入要领是三个字：**快、准、狠**[](https://m.163.com/dy/article/KNRJCVI205568W0A.html)。

|条件|具体标准|
|---|---|
|**时间窗口**|最佳买入时段：9:30-10:00（资金态度最明确）；次选：14:30-14:55（尾盘确定性高）|
|**技术信号**|① 开盘30分钟内放量突破前日高点  <br>② 分时图均线上方运行，回踩不破均线[](https://m.163.com/dy/article/KNRJCVI205568W0A.html)  <br>③ 板块内有2只以上涨停股带动|
|**资金确认**|主力资金净流入且超大单净流入占比 > 30%|
|**放弃条件**|错过最佳买点（如涨停板打开后回封失败），宁可错过不做错[](https://m.163.com/dy/article/KNRJCVI205568W0A.html)|

### 4.2 卖出规则

短线卖出可以记住这5条简明纪律[](https://m.hexun.com/news/2025-09-12/221310398.html)：

|信号|操作|
|---|---|
|涨幅超7%却未涨停|立即卖出（主力诱多信号）|
|低开超3%，2分钟内未翻红|立即止损|
|连续上涨3天|卖出一半仓位|
|高位出现巨量成交|全部清仓|
|跌破5日均线|无条件止损|

**止盈止损的硬性标准**：

- 止损：亏损达到**5%-8%** 无条件离场[](https://m.163.com/dy/article/KNRJCVI205568W0A.html)
    
- 止盈：盈利超过10%后，移动止盈线设在5%回撤位置
    

## 五、模块④：仓位管理——每次买多少

### 5.1 仓位分配原则

短线交易的核心原则：**每次开仓资金控制在可用资金的三到四成**[](https://m.163.com/dy/article/KNRJCVI205568W0A.html)。

|账户规模|单只股票仓位上限|同时持仓数量|
|---|---|---|
|10万以下|20%-30%|2-3只|
|10-50万|15%-20%|3-5只|
|50万以上|10%-15%|4-6只|

### 5.2 分批建仓方法

以单只股票计划投入总资金的20%为例：

|批次|仓位比例|触发条件|
|---|---|---|
|第一批|10%|开盘30分钟内确认强势|
|第二批|10%|回踩分时均线不破（或尾盘确认）|

### 5.3 日内交易频率控制

**如果当天连续止损2次，立即停止当天所有交易**[](https://m.163.com/dy/article/KNRJCVI205568W0A.html)。

这是防止情绪化交易的最重要纪律。连续亏损说明：

- 要么当天市场环境不适合你的系统
    
- 要么你的判断已经出现了偏差
    

停下来复盘，而不是继续交易试图"扳回来"。

## 六、模块⑤：复盘优化——如何持续改进系统

### 6.1 每日复盘记录模板

每笔交易完成后，记录以下信息：

|项目|记录内容|
|---|---|
|股票代码/名称||
|买入日期/价格||
|卖出日期/价格||
|盈亏比例||
|买入依据|满足哪些选股条件|
|卖出依据|触发哪条卖出规则|
|实际走势与预期是否一致||
|操作偏差|是否严格执行了规则|

### 6.2 定期统计核心指标

每周或每月统计以下数据[](https://futures.hexun.com/2024-09-20/214622923.html)：

|指标|计算公式|目标参考值|
|---|---|---|
|**胜率**|盈利交易次数 / 总交易次数|>55%|
|**盈亏比**|平均盈利 / 平均亏损|>1.5|
|**最大回撤**|账户净值从高点到低点的最大跌幅|<15%|
|**期望值**|胜率 × 平均盈利 - (1-胜率) × 平均亏损|正值|

### 6.3 系统优化的方向

根据统计结果，有针对性地调整：

|问题表现|可能原因|优化方向|
|---|---|---|
|胜率高但盈亏比低|止盈过早或止损过宽|放宽止盈条件，收紧止损|
|盈亏比高但胜率低|买点选择过于激进|提高买入标准，等待更确定信号|
|最大回撤过大|仓位过重或止损不严|降低单只仓位，严格执行止损|
|连续亏损后出现大亏|情绪化交易|严格执行"2次止损后暂停"规则|

### 6.4 一个简单的优化迭代流程

text

第1步：每周统计胜率、盈亏比、最大回撤
第2步：分析亏损交易，找出共性原因
第3步：针对问题调整1-2条规则
第4步：用调整后的规则交易2周
第5步：对比调整前后的统计数据
第6步：保留有效改进，继续迭代

每日流程：
┌─────────────────────────────────────────┐

│ → 板块资金流向分析 → 筛选观察池（5-8只）    │
├─────────────────────────────────────────┤
│ 次日开盘前（8:30-9:15）                   │
│ → 查看隔夜新闻 → 确认当日重点标的（3-5只） │

│ → 持仓监控 → 触发卖出条件则执行            │

**短线交易成功的核心要素**：

1. **规则明确**：每一笔交易都有清晰的买入和卖出依据
    
2. **纪律执行**：规则写在纸上，更刻在脑子里，亏损时不幻想[](https://m.163.com/dy/article/KNRJCVI205568W0A.html)
    
3. **频率控制**：连续亏损2次即停止，不报复性交易[](https://m.163.com/dy/article/KNRJCVI205568W0A.html)
    
4. **持续复盘**：用数据说话，不断优化系统
