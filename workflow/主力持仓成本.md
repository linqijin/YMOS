# 主力持仓成本涨幅评估

## 一、原理说明

主力吸筹过程中会形成一个"平均持仓成本线"。当股价接近成本线时，意味着：
- 主力尚未大幅盈利，拉升意愿强
- 安全边际高，介入风险低
- 后续上涨空间大

反之，当股价远高于成本线时：
- 主力已有较大浮盈，可能随时派发
- 介入风险增加
- 需谨慎判断是否已进入出货阶段

---

## 二、估算方法

由于无法获取真实的Level2筹码分布数据，采用成交量加权均价作为主力成本的近似估算：

```
成本线 = Σ(每日收盘价 × 当日成交量) / Σ(成交量)
```

计算周期：默认60个交易日（可调整）

### 为什么用成交量加权？

1. 主力吸筹必然伴随成交量放大
2. 成交量大的日子，主力参与度高，其成本更接近当日价格
3. 加权均价反映了主力"平均入场位置"

---

## 三、涨幅计算

```
涨幅百分比 = (当前股价 - 成本线) / 成本线 × 100%
```

示例：
- 成本线：10元
- 当前价：11元
- 涨幅：(11-10)/10 = 10%

---

## 四、得分映射

| 涨幅区间 | 得分 | 含义 |
|:---|:---|:---|
| < 10% | 100分 | 成本线附近，高安全区 |
| 10-20% | 75分 | 轻度盈利，中安全区 |
| 20-30% | 50分 | 中度盈利，低安全区 |
| > 30% | 0-50分 | 大幅盈利，需谨慎 |

得分公式：
```python
if gain_pct < 10:
    score = 100
elif gain_pct < 20:
    score = 75
elif gain_pct < 30:
    score = 50
else:
    score = max(0, 100 - gain_pct * 2)
```

---

## 五、安全等级定义

| 等级 | 涨幅条件 | 操作建议 |
|:---|:---|:---|
| **A级** | < 10% | 高安全，可积极介入 |
| **B级** | 10-20% | 中安全，可适度介入 |
| **C级** | 20-30% | 低安全，谨慎观察 |
| **D级** | > 30% | 风险较高，建议回避 |

```python

    """
    主力成本涨幅评估
    
    :param ts_code: 股票代码
    :param lookback: 计算周期（天数）
    :return: (score, cost_line, gain_pct)

    df = dm.get_daily_prices(ts_code, lookback)
```

## 七、注意事项

1. **估算局限性**：成交量加权均价是近似值，无法精确反映主力真实成本
2. **周期选择**：
   - 60日：反映近期主力行为，适合短线
   - 120日：覆盖更长期吸筹，适合中长线
3. **特殊情况**：
   - 新股上市不足周期天数，数据不完整，给中性分50
   - 成本线为0时（数据异常），跳过该维度
4. **配合使用**：成本涨幅需与其他维度（控盘评分、筹码集中度等）综合判断
